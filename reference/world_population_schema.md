# `world_population.yaml` schema

`world_population.yaml` gives the number of people in each **0.5° × 0.5°** tile of the Earth. It uses
the same grid as `world_map.yaml`: **720 × 360 = 259,200 tiles**, with the same tile ids (e.g.
`N395W1055`), the same file order and the same `neighbors` links. Coordinates, tile ids, ordering and
wrapping work exactly as in `world_map_schema.md` §2 and `grid.py`.

The file is generated by `gen_population.py` (with `ghsl.py`) from the GHSL population raster and
`ne_10m_admin_0_countries.geojson`. Don't edit it by hand. `convert_population.py` turns it into
`world_population_current.json`, its columnar copy. This full modern world is prototype and
demonstration data; the game starts from `world_population_start.json` (see `gen_start_capitals.py`).

## Source

- **Population:** European Commission JRC, Global Human Settlement Layer, **GHS-POP R2023A, epoch
  2020**, WGS84 at 30 arc-seconds (about 1 km).
  - Page: https://human-settlement.emergency.copernicus.eu/download.php?ds=pop
  - Data: https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/GHSL/GHS_POP_GLOBE_R2023A/GHS_POP_E2020_GLOBE_R2023A_4326_30ss/V1-0/GHS_POP_E2020_GLOBE_R2023A_4326_30ss_V1_0.zip
- **Regridding:**
  - Every ~1 km source cell is added to the tile that contains its centre. That's about 3,600 cells
    per tile at the equator, so tile totals are real sums, not estimates.
  - The raster is two columns wider than 360°, so cells whose centres fall outside −180°..180° are
    dropped rather than wrapped, so nothing is counted twice.
  - Tile totals are rounded to whole people. The world total is **7,840,952,769**.
- **Coverage is 89.1°S–89.1°N**, which is all inhabited land.
- **Countries:** Natural Earth 1:10m Admin 0 Countries, which uses de facto boundaries:
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_0_countries.geojson
  - Polygons are filled on a 0.025° grid (400 cells per tile), and each tile takes the code that
    covers the most of its land.
  - Tiles whose only land is islands smaller than one grid cell fall back to counting the polygon
    points that fall inside the tile.

## Top level

```yaml
map:   { ... }   # grid metadata and source info
tiles: { ... }   # 259,200 tiles keyed by tile id
```

`map` has the same grid keys as `world_map.yaml` (`projection`, `tile_size_degrees`, `width`, `height`,
`tile_id_format`, `wraps_east_west`, `wraps_north_south`), plus:

| key | meaning |
|-----|---------|
| `population_source_page` / `population_source_data` | URLs above |
| `population_source_dataset` | `JRC GHSL GHS-POP R2023A, epoch 2020, 30 arc-seconds` |
| `population_year` | `2020` |
| `population_coverage` | `{south_lat: -89.1, north_lat: 89.1}`, the latitude band the source covers |
| `total_population` | sum of every tile's `population` |
| `country_source_data` | URL of the Natural Earth file above |
| `country_code_standard` | `ISO 3166-1 alpha-3` |

## Tiles

```yaml
  N405W0740:
    lat: 40.5
    lon: -74.0
    center: [40.75, -73.75]
    country: USA
    population: 9376910
    area_km2: 2341.7
    density_per_km2: 4004.33
    neighbors: {n: N410W0740, ne: N410W0735, e: N405W0735, se: N400W0735, s: N400W0740, sw: N400W0745, w: N405W0745, nw: N410W0745}
```

| key | type | meaning |
|-----|------|---------|
| `lat`, `lon`, `center`, `neighbors` | | Same as `world_map.yaml` |
| `country` | string or `null` | ISO 3166-1 alpha-3 code of the country or territory with the **most land** in the tile, not the most people. `null` = no land in the tile (open ocean, most of the 164,568 such tiles), or only unclaimed or contested land. |
| `population` | int | People living in the tile in 2020, rounded to the nearest whole person |
| `area_km2` | float | Whole-tile surface area, land and water, on a sphere of radius 6371.0072 km |
| `density_per_km2` | float | `population / area_km2`. Coastal tiles get a low figure because water counts in the area. |

## Notes

- 49,910 tiles have people. The most populous are Delhi (`N285E0770`, 25.6 million), Jakarta
  (`S065E1065`), Cairo (`N300E0310`), Dhaka (`N235E0900`), Tokyo (`N355E1395`) and Shanghai
  (`N310E1210`).
- Codes cover territories as well as sovereign states, following ISO 3166-1. So Greenland is `GRL`,
  Puerto Rico `PRI`, Hong Kong `HKG`, Taiwan `TWN`, Western Sahara `ESH` and Antarctica `ATA`.
- Areas Natural Earth gives no ISO code are mapped as follows:
  - Somaliland → `SOM`.
  - Northern Cyprus and the Cyprus buffer zone → `CYP`.
  - The Akrotiri and Dhekelia bases → `GBR`.
  - Guantanamo Bay → `CUB`.
  - Siachen Glacier → `IND` (de facto).
  - Kosovo gets `XKX`, a user-assigned code used by the EU and IMF that is not an official ISO code.
  - Bir Tawil, the Southern Patagonian Ice Field, the Spratly Islands, Scarborough Reef, Bajo Nuevo
    and Serranilla count as no owner.
- 461 tiles have people but `country: null`, about 338,000 people in all. They are mostly sea tiles
  beside small islands and coasts (the largest are in the Philippines, Indonesia and China), where
  GHSL places people but Natural Earth's 1:10m outlines show no land.
- `world_map.yaml` takes its coastlines from a satellite image, so they don't always match this data.
  555 tiles that it marks as 100% water have people here, 765,000 in total. They are mostly atolls and
  small islands, such as `N040E0735` with Malé in the Maldives.
- `world_population_preview.txt` shows people per km² for every fourth tile in each direction (one
  character per 2°): ` ` 0, `.` <1, `:` <10, `-` <50, `+` <150, `*` <400, `#` 400+.
